# ReIndev Discord RPC

![GitHub Downloads (all assets, all releases)](https://img.shields.io/github/downloads/kingcolton1/ReIndev-Discord-RPC/total)

Discord RPC for ReIndev. Show off your activity status when you play ReIndev!

Support on client side ONLY, and ReIndev 2.9 or up.

There are two settings to configure:

`Dimension Visibility` - Toggle to display or hide dimension you are on.

`Server IP Visibility` - Toggle to display or hide server IP you are connected to.

## Known Bugs
See [issues](https://github.com/KingColton1/ReIndev-Discord-RPC/issues).

## Other
The config file is in `config/reindev-discord-rpc.conf`. You can change those configs in-game by going to Mods button on top-right, then look for `ReIndev Discord RPC`, then click `Configure Mod` and you can toggle settings however you want.
